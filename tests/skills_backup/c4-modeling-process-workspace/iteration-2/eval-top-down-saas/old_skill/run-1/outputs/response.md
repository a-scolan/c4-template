Ordre recommandé pour partir de zéro sur un produit SaaS en LikeC4 :

1. **C1 — Contexte** : frontière du système, acteurs, systèmes externes.
2. **C2 — Containers** : unités runtime / déployables et leurs relations.
3. **C3 — Components** : groupes logiques internes aux containers qui le méritent.
4. **Deployment** — optionnel.
5. **Dynamic / Use Cases** — optionnel.
6. **Validation** à la fin.

La logique reste simple : on conçoit de haut en bas, jamais à partir du code.

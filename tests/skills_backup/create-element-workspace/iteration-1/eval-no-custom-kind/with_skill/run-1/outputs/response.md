Plutôt **non** dans ce repo, tant que tu n’as pas vérifié le shared spec.

1. Regarde d’abord les kinds existants via `read-project-summary` ou `projects/shared/spec-*.c4`.
2. Si un kind existant comme `Container_Api` ou `Container_Webapp` couvre déjà le besoin, réutilise-le.

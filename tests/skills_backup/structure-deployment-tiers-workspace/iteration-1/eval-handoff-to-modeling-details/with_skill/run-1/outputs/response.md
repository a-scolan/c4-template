Ce skill sert à **structurer les tiers** : responsabilités de `Dmz` / `AppTier` / `ProcTier` / `DataTier`, isolation réseau et règles firewall entre zones.

Pour les **noms exacts des VM**, la **hiérarchie détaillée**, les **tables Markdown de specs** et les liens **`instanceOf`**, passe à **`model-deployment-infrastructure`**.

Si tu veux verrouiller encore plus finement la convention de nommage, **`name-deployment-nodes`** peut compléter ce travail. Mais le handoff principal reste `model-deployment-infrastructure` pour tout le détail d'infrastructure.

Un **C1 doit rester statique** : il montre la **frontière du système** et son **contexte**.

Si tu veux raconter `user -> webapp -> api` dans le temps, mets ce diagramme dans **`views 'Use Cases'`** sous forme de **`dynamic view`**.

Pourquoi : **C1** répond à *qui interagit avec le système ?* ; une vue dynamique répond à *dans quel ordre le scénario se déroule-t-il ?*.

La règle de décision est simple : **la vue C3 est sélective**, pas obligatoire pour chaque container.

- **Pas de C3** si ton container API est **petit, clair, et déjà compréhensible en C2**.
- **Faire une C3** seulement si le container est **complexe ou critique**, et qu’il faut montrer sa structure interne en **groupements logiques de code** (pas des classes).

En bref : **si la C2 explique déjà suffisamment “comment c’est construit”, inutile d’ajouter une C3**.  
La C3 sert seulement quand elle **apporte une vraie compréhension supplémentaire**.

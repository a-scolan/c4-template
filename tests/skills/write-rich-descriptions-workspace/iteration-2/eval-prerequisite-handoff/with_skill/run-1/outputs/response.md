Commence par le bon prérequis : on ne décrit pas richement un élément qui n’existe pas encore.
1. Crée d’abord le service système avec `create-element`.
2. Pour le VM de prod / l’infrastructure de déploiement, passe par `model-deployment-infrastructure`.
3. Une fois les éléments créés, choisis le format :
   - système : `metadata {}` seulement si un champ doit être requêté / filtré ;
   - déploiement : tableau Markdown lisible par les ops.

The clean default is to create a Deployment view first, and add a C2 only if the dedicated services are real logical containers that deserve their own application-level explanation. Bastion hosts, firewalls, and the new SecZone itself are infrastructure concerns, so they belong in views Deployment. Add a C2 container view only when those dedicated services are part of the system model and stakeholders need parent plus focus plus neighbors at the logical level. Do not create a C2 just to redraw bastion or firewall topology.

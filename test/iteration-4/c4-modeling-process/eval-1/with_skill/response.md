No, not automatically. A C3 view is not required for every container. Create C3 only when the container is architecturally central, risky, hard to reason about, or internally complex enough that C2 no longer explains it well. If the API container is simple and its role is already clear from C2, stop at C2. Components are logical code groupings, not deployable units, so do not add a C3 view just for completeness.

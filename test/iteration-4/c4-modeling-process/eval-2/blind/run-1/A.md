No. A C1 diagram is for actors and systems, not for time-ordered steps, and a webapp plus an API are containers rather than C1 systems. If you want the structure, show user-to-system at C1 and webapp-to-API at C2. If you want temporal arrows for a user journey, put that in a separate sequence/scenario diagram, because time and order are behavioral concerns while C1, C2, and C3 are structural.

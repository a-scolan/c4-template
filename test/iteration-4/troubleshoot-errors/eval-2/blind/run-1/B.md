`sends` is definitely wrong in this repository. `projects/shared/spec-global.c4` defines model relationship types `uses`, `calls`, `async`, `reads`, and `writes`, while `projects/shared/spec-deployment.c4` defines deployment types such as `http`, `https`, `tcp`, `amqp`, `sql`, `redis`, and `smtp`; `sends` is in neither list.

So diagnose this in two passes. First, replace `sends` with the correct declared relationship type for the level you are modeling. Second, validate `dataLayer.cache` as a real alias path. That path only works if `dataLayer` is an actual declared parent alias and `cache` is its child. If `cache` is declared directly, the right reference may be `cache` or a fuller FQN such as `system.cache` instead. In short: the relationship name is definitely wrong, and the FQN may also be wrong.

Not as a general rule. paymentsCore is a project-specific system, so it should stay in the payments project, not in the shared specifications area. Shared specs are for reusable definitions such as kinds, tags, relationships, colors, sizes, and common assets. backOfficeUser should also not be dropped into shared specs just to make it globally visible; only put it in a shared or common model if it is truly a reusable cross-project actor. Cross-project references should stay explicit, minimal, and documented. Avoid making projects include each other in a circular way, and do not move project-owned business elements into shared just for convenience.

Bootstrap the new payments project from a minimal baseline, not by cloning an example as-is. Create projects/payments with three minimum files: likec4.config.json, system-model.c4, and system-views.c4 or equivalent payments-specific filenames. In the config, give the project its own name and title, set include.paths to the shared area using a relative path such as ../shared, and keep image aliases consistent with the rest of the workspace. In the model file, define only payments-owned elements; in the views file, add the smallest useful initial views. Add sequence, deployment, or operations files later only if the payments project actually needs them.

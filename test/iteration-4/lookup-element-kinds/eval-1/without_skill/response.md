Between an application VM and a database VM in deployment, use sql when you want to model database traffic precisely. tcp is the generic transport-level fallback, and calls is not a deployment relationship in this workspace. The deployment relationship set is defined in projects/shared/spec-deployment.c4. In the logical application model, the valid relationship kinds remain uses, calls, async, reads, and writes from projects/shared/spec-global.c4, with reads and writes being the best fit for application-to-database behavior. The shared cheat sheet also says normal application traffic should usually stay in the logical model and flow into deployment through instanceOf, so add explicit deployment edges only when you need infrastructure-specific detail.

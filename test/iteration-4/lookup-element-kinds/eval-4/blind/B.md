For a web application talking to an API in the logical model, use calls, not https. The logical relationship kinds are defined in projects/shared/spec-global.c4, and https is not one of them. If you want to record the protocol, keep the logical relationship kind as calls and capture HTTPS as the interaction technology. The relationship kind https becomes valid only in deployment or infrastructure modeling, because it is declared in projects/shared/spec-deployment.c4 as a deployment relationship.

Use Container_Api for a backend API or service. Container_API is not declared in the shared taxonomy, and Container is only the generic base kind. In projects/shared/spec-containers.c4, the relevant C2 taxonomy is the base Container plus specialized kinds such as Container_Api and Container_Database. In the logical model, the relationship kinds defined in projects/shared/spec-global.c4 are exactly uses, calls, async, reads, and writes. Toward a database, the database-specific choices are reads and writes; uses is only the generic fallback, while calls is the synchronous service-call relationship rather than the database-specific one. To verify in this workspace, inspect the element declarations in projects/shared/spec-containers.c4 and the relationship declarations in projects/shared/spec-global.c4.

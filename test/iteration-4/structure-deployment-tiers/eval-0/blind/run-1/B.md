Use a Production environment with explicitly nested sibling zones: Dmz, AppTier, ProcTier, DataTier, and SecZone for monitoring. Dmz handles Internet-facing edge concerns only; AppTier contains business services and is internal-only; ProcTier is for asynchronous processing only; DataTier contains persistent storage and is never Internet-facing; SecZone is the optional monitoring and security tier for Prometheus, Grafana, logs, and alerting. Keep the hierarchy clear as Environment to Zone to VM to service instance, keep one primary responsibility per tier, and document firewall rules in the zone descriptions so the security boundary is obvious.

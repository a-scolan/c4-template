Add the Prometheus scrape as a deployment relationship, because it is infrastructure or observability traffic rather than duplicated business traffic. Model Prometheus as a deployment node and connect it with http or https to the real scrape target: Prometheus -> apiVm if it scrapes VM-level metrics, or Prometheus -> apiApp if it scrapes the application metrics endpoint. Avoid re-adding browser -> API traffic that already exists in the logical model, and avoid duplicating other normal application flows that instanceOf already brings into deployment.

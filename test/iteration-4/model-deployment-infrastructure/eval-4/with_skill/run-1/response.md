Add the Prometheus scrape if Prometheus is an operational or infrastructure actor that is not already represented by an inherited logical relationship. Monitoring traffic is exactly the kind of deployment-specific edge worth modeling. Good candidates to add in deployment are Prometheus scraping the API VM or Node_App, backup agents writing to backup storage, bastion or admin access, log shipping or SIEM forwarding, and database replication. Avoid duplicating anything that already exists in the logical model and will be inherited through instanceOf, especially browser to API traffic, API to service calls, or service to database calls.

Use the shared deployment kinds and keep the nesting strict: production environment, zones inside it, one infrastructure node per deployable responsibility named Environment plus Service plus Vm, and one Node_App inside each VM. Link each deployed app to the logical model with instanceOf pointing to the container FQN from the system model. Do not copy normal deployment relationships manually because LikeC4 inherits them automatically through instanceOf. Put technologies such as HTTPS or database ports on the logical system-model relationships, not on duplicated deployment edges. Add deployment relationships only for infrastructure-specific flows such as monitoring, backups, bastion access, log shipping, or replication. Also give each VM a rich Markdown description table with network interface first, then OS, CPU, RAM, port, and RTO; zone descriptions should carry VLAN, CIDR, and firewall context.

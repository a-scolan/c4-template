Use the shared deployment shape Node_Environment -> Zone -> Node_Vm. For this production setup, I would name it as: Environment = Prod; Zones = Dmz, AppTier, ProcTier, DataTier, Monitoring; VMs = apiGatewayVm, uploadVm, workerVm, mongoDbVm, monitoringVm. A clean mapping is Dmz -> apiGatewayVm, AppTier -> uploadVm, ProcTier -> workerVm, DataTier -> mongoDbVm, Monitoring -> monitoringVm. Fix the candidates as follows: ProdApiVM -> apiGatewayVm (or prodApiGatewayVm if you need one flat global VM identifier), prod_upload_vm -> uploadVm (or prodUploadVm in the flat form), AppServers -> AppTier if it is a zone or appCluster if it is actually a server group, MonitoringTier -> Monitoring. Keep one rule everywhere: short PascalCase names for the higher-level environment/zone identifiers, and readable VM identifiers that end with Vm.

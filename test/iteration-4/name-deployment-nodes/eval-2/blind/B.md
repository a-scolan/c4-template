Prefer ProdEuApiVm over EuProdApiVm. The readable convention is Environment + Region + Role + Kind, so keep the same order across everything: ProdEuAppTier, ProdEuApiVm, ProdEuWorkerVm, ProdEuMongoDbVm, ProdUsApiVm. If you want to stay closest to the shared examples where VM instances look like apiVm, the lowerCamelCase equivalent would be prodEuApiVm. The important part is consistency: do not mix ProdEu... and EuProd... in the same model.

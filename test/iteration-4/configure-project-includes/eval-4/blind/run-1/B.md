Set `include.paths` so `../shared` stays first and `../platform-shared` comes after it. Then leave the current alias used by the existing shared specs pointed at `../shared/images`, and give platform images a separate alias such as `@platform` -> `../platform-shared/images`. Do not merge both roots under the same alias when relative image names overlap, because one source will shadow the other and current `@/...` references may resolve differently.

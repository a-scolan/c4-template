Apply the brokered async pattern already present in the model: `Container_Api` --`async`--> `Container_Queue` (RabbitMQ) --`async`--> the worker, ideally as a `Container_ProcessingServer` if it is a background processor. The mistake to avoid is collapsing this into a direct API-to-worker call, or a single API-to-worker edge labeled "RabbitMQ", because that hides the queue and makes the flow look synchronous.

Use five logical deployment tiers: `Dmz` for internet-facing ingress such as the API gateway/WAF, `AppTier` for synchronous business services, `ProcTier` for `RabbitMQ` plus the async worker path, `DataTier` for persistent stores (`MongoDB`, `MinIO`), and `OpsTier` for monitoring. Key rules: the Internet reaches only `Dmz`; `Dmz` may call `AppTier` over HTTPS; `AppTier` may use `ProcTier` for async handoff and may reach `DataTier` only where the request path truly needs it; `ProcTier` may talk to `DataTier` but should have no public ingress; `OpsTier` may collect or scrape telemetry from all tiers but should not sit on the user request path. Deny direct `Dmz -> DataTier`, `Dmz -> ProcTier`, and broad east-west traffic by default; open only explicit least-privilege ports between adjacent tiers.

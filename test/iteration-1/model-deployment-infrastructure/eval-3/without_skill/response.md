Usually no: if Prod.Web.webApp -> Prod.App.apiApp and Prod.App.apiApp -> Prod.Data.dbApp are just the runtime instances of logical interactions that already exist, put the technology such as HTTPS or the database protocol on the logical relationships and let deployment reuse that meaning. Keep ports as deployment metadata or descriptions when they are environment-specific. Add explicit deployment relationships only when the connection is deployment-specific and not already present in the logical model, such as ingress hops, service-mesh traffic, monitoring scrapes, backup flows, or replication.

Use a deployment hierarchy like Prod -> Dmz/AppTier/ProcTier/DataTier -> VM -> Node_App. Put the API gateway Node_App on a VM in Dmz, the upload service Node_App on a VM in AppTier, the processing worker Node_App on a VM in ProcTier, and the MongoDB Node_App on a VM in DataTier. Each Node_App should link to the logical model with instanceOf pointing at the corresponding logical element. Normally you should not copy logical application relationships manually into deployment just to make them visible; add deployment relationships only when they represent deployment-only behavior such as monitoring, replication, load balancers, health checks, or other runtime infrastructure links.

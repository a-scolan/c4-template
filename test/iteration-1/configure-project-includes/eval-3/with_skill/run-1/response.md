This skill is enough only for the project-local part: creating or adjusting the new project's `likec4.config.json`, relative `include.paths`, image aliases, and a small internal file split. If you are deciding overall workspace structure, shared-folder boundaries, or how multiple LikeC4 projects should be organized together, it should be combined with `organize-multi-project`. Short version: use this skill for the local config; use `organize-multi-project` for the bigger multi-project design.

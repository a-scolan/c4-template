For deployment between an app VM and a database VM, use the deployment taxonomy from `projects/shared/spec-deployment.c4`: `sql` is the most specific and usually the best fit for database traffic, while `tcp` is valid only if you want a generic transport-level edge and do not want to model it specifically as SQL. `calls` is not a deployment relationship kind here, so do not use it between deployment nodes. In the logical application model, the valid relationship kinds are the logical ones from `projects/shared/spec-global.c4`: `uses`, `calls`, `async`, `reads`, and `writes`. For an application talking to a database in the logical model, prefer `reads` and `writes`; `calls` is generally for application/service behavior rather than database access.

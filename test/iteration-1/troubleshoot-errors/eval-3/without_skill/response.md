The root cause is that the same traffic was modeled twice at two different abstraction levels, and the protocol name was put in the wrong vocabulary once. In this workspace, `https` is a deployment/infrastructure relationship from `projects/shared/spec-deployment.c4`, while model relationships are `uses/calls/async/reads/writes` from `projects/shared/spec-global.c4`. The cheat sheet also says to put interaction technology on the system-model relationship and to use deployment relationships only for infrastructure-specific connections. Clean fix: keep the logical app-to-app interaction once in `model {}` with a model relationship such as `calls` plus `technology 'HTTPS'`, let deployed instances inherit that via `instanceOf`, and only add a separate deployment `https` edge when it represents a distinct infrastructure hop rather than the same application traffic repeated.

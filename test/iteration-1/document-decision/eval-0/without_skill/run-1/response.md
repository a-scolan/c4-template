Yes. This is a classic ADR. Frame it around why the primary operational data store should be relational for this system. Suggested title: Choose PostgreSQL as the primary database instead of MongoDB. Context: describe the workload, data relationships, transaction needs, query patterns, reporting needs, operational constraints, and team expertise. Decision: adopt PostgreSQL for the main database container and reject MongoDB for this core workload. Consequences: pros include ACID transactions, referential integrity, mature migrations, SQL reporting, and a strong tooling ecosystem; cons include less schema flexibility and more upfront data modeling. Alternatives to record: MongoDB as the primary store, polyglot persistence, or PostgreSQL plus JSONB for selective document-style data. Also capture backup, HA, migration, and the conditions that would justify revisiting MongoDB later.

No—do not keep `Prod.Web.webApp -[https]-> Prod.App.apiApp` in deployment just to make browser traffic visible. In this workspace, protocol and interaction semantics live on the logical element relationships in `projects/template/system-model.c4`: `User -> webapp` carries `Manual`, `webapp -> api` carries `HTTPS`, and the API/database links carry `PostgreSQL` on separate `reads`/`writes` relationships. Deployment should primarily show where instances run and let those logical relationships be inherited. So: `Manual` belongs on actor -> web app, `HTTPS` belongs on the logical web app -> API relationship, and `HTTP/8080` belongs only on a real direct runtime/service hop if that hop actually exists (for example proxy -> API), not as an invented deployment-only browser edge.

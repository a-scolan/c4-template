In this repo, bootstrap projects/payments/ by following the shape already visible in projects/template/: create projects/payments/likec4.config.json, one model file such as system-model.c4, and one view file such as system-views.c4; that is the minimum clean setup. In the config, give the project its own name/title, include the payments files plus only the shared spec files and images it actually needs, and keep payments-owned business elements inside projects/payments/, not under projects/shared/. Add an ADR/ folder only if you want the same decision-record convention as the template project.

Bootstrap the new project from a minimal baseline, not by copying an example project wholesale. Create a new folder such as `projects/payments/` and add exactly these starter files: `likec4.config.json`, `system-model.c4`, and `system-views.c4`. In `likec4.config.json`, give the project a unique `name` and `title`, point `include.paths` to `../shared`, and keep image aliases consistent with the rest of the workspace. Then put only payments-domain model content in `system-model.c4`, and the first useful views in `system-views.c4`. Expand later only if needed with extra files for deployment, dynamic views, or operations. A clean starting checklist is: 1) create `projects/payments/`; 2) add local config; 3) wire shared includes with relative paths; 4) add a minimal model file; 5) add a minimal views file; 6) remove any example-specific names if you used a local scaffold.

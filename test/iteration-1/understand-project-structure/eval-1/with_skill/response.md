After switching projects, assume your old context is stale. Re-run these checks before touching the C3 view: list-projects, read-project-summary for the explicit project, then search-element or read-element for the parent system/container whose components the view shows. Offline, also reopen the destination project's likec4.config.json and compare it with projects/shared/SPEC_CHEATSHEET.md and the shared spec files. Lock in the real parent boundary, valid C3 kind Component, and allowed relationships such as uses, calls, async, reads, writes. This prevents wrong project IDs, wrong FQNs, wrong parent containers, and example-driven edits.

That is not correct for C1.

C1 (System Context) should show static context: people, your system, and external systems. It answers “who interacts with what,” not “in what time order.”

Temporal arrows and step-by-step user journeys belong in a dynamic view, where sequence/ordering is explicit.

Why:
- C1 stays high-level and audience-friendly.
- Dynamic view captures chronology, request/response order, branches, and scenario intent.

So keep C1 for context, and put the user journey in a dynamic diagram tied to the relevant C2/C3 scope.

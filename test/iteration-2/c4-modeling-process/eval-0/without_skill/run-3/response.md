Use this LikeC4 sequence from blank page:
1) Frame the problem: business scope, actors, core outcomes, non-goals.
2) Build C1 context: primary users, your system, external systems, trust boundaries.
3) Build C2 containers: major building blocks, technologies, and key dependencies.
4) Validate C2 with real use cases and operational constraints.
5) Add C3 selectively for complex or high-risk containers only.
6) Add deployment views for production/runtime topology.
7) Add dynamic views for time-ordered scenarios.
8) Iterate and harden: naming, tags/metadata, descriptions, and consistency checks.

Optional:
- C3 for trivial containers
- Dynamic views when sequence is not needed yet
- Deep deployment detail before infra decisions settle
- Advanced styling/layout tuning during early modeling

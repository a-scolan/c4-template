`backend.api` is unresolved because names like `backend` are not global once they are nested inside another element. In `base.c4`, `backend` is declared inside `cloud`, and `api` is declared inside `backend`, so its full identifier is `cloud.backend.api`. In another file such as `ops.c4`, you are no longer inside the `cloud` scope, so `backend.api` is interpreted as a top-level path starting from `backend`, and no such top-level element exists. Cross-file references must use the element's fully qualified name (FQN), not the shorter relative path that only makes sense inside the parent scope. The corrected relationship is: `cloud.backend.api -> cloud.db`.

Use the repository in two passes. First create the template baseline from projects/template/: split the 1200-line system.c4 into system-model.c4 for all model definitions and relationships, and system-views.c4 for all views. Then, once it grows, split like projects/spec-showcase/: actors-systems.c4 for actors, systems, and C1 relationships; containers.c4 for C2 containers and their relationships; components.c4 for C3 internals; context-views.c4 for C1 views; container-views.c4 for C2 views; and component-views.c4 for C3 views. Add deployment.c4 plus deployment-views.c4 when you introduce deployment nodes, and add use-case-views.c4 and operations-views.c4 for scenario and operational slices. Keep Use Cases, Deployment, and Operations as separate view files/categories; only create extra model files for them if they introduce new modeled elements rather than just alternate views.

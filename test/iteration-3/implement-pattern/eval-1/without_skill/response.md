Apply the queue/worker pattern already shown in the repository: `api = Container_Api`, `queue = Container_Queue 'RabbitMQ'`, and `worker = Container_ProcessingServer 'Worker'`, then model `api -[async]-> queue 'Publishes job' { technology 'AMQP' }` and `queue -[async]-> worker 'Delivers job' { technology 'AMQP' }`. The main mistake to avoid is drawing a direct `api -> worker` execution path and treating RabbitMQ like a side note; make the broker a first-class element and use `async`, not `calls`, for those hops.

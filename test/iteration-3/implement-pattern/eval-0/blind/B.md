To stay consistent with this template, model the internal service as `Container_Api` and the provider as `System_External 'Payment Provider'` (optionally with an external `Container_Api` inside it if you need endpoint detail). Connect them with `-[calls]->` and `technology 'HTTPS'`, with a verb such as 'Creates payment' or 'Authorizes payment'. If you also keep a context view, add the same dependency at system level from your system to the external provider. Avoid using `reads`/`writes` for the provider or modeling it as an internal container; this is an outbound service call to an external system.

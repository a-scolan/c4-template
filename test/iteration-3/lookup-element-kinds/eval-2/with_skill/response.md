The exact deployment kind for a firewall in this repository is `Infra_Fw`; `projects/shared/spec-deployment.c4` declares `Infra_Fw` and does not declare `Infra_Firewall`. Two nearby valid deployment kinds are `Infra_F5` and `Infra_Router`; `Node_Vm` is also valid if you need a VM rather than a network appliance. To verify in the active workspace, use `read-project-summary` in a normal LikeC4 workflow and cross-check `projects/shared/spec-deployment.c4`.

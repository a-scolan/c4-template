For a web application talking to an API in the logical model, use `calls`, not `https`. In this workspace, the protocol belongs in the relationship metadata, for example `webapp -[calls]-> api` with `technology 'HTTPS'`. That exact pattern appears in `projects/template/system-model.c4` and `projects/spec-showcase/containers.c4`. `https` becomes valid only when you are using deployment/infrastructure relationships, because `relationship https` is declared in `projects/shared/spec-deployment.c4`, not in `projects/shared/spec-global.c4`. The guidance in `projects/shared/SPEC_CHEATSHEET.md` is that normal application traffic should usually stay in the system model and then be inherited into deployment through `instanceOf`; use deployment `-[https]->` only for infrastructure-specific connections such as VM-to-VM ingress.

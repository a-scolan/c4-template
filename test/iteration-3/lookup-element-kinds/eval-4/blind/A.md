For a web application talking to an API in the logical model, use `calls`, not `https`. In this workspace, the protocol belongs in the relationship `technology` field—for example `webapp -[calls]-> api { technology 'HTTPS' }`—which is exactly how `projects/template/system-model.c4` and `projects/spec-showcase/containers.c4` model it. The relationship kind `https` becomes valid only on deployment-side infrastructure relationships, because `projects/shared/spec-deployment.c4` declares `https` as a deployment relationship while `projects/shared/spec-global.c4` declares `calls` for the logical model. To confirm in the active workspace, use `read-project-summary` in a normal workflow and cross-check those shared specs.

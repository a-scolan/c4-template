Use the production environment as the parent, then nest `Dmz`, `AppTier`, `ProcTier`, and `DataTier` explicitly under it, with optional `SecZone` for monitoring/security and `InfraZone` for backup or DR. Put the API gateway and any web edge in `Dmz`; put the business services in `AppTier`; put RabbitMQ and the async worker in `ProcTier`; put MongoDB and MinIO in `DataTier`. Keep `DataTier` internal only and never Internet-facing. Typical network rules are Internet -> `Dmz` on HTTPS 443 only, `Dmz` -> `AppTier` on internal HTTP/HTTPS, `AppTier` -> `ProcTier` on AMQP 5672 for job publishing, `AppTier` and `ProcTier` -> `DataTier` on database and storage ports such as 27017 and 9000, `SecZone` scraping metrics from internal tiers, and `DataTier` -> `InfraZone` for backup or replication if you add DR.

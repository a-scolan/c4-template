First re-establish the workspace rules and active project context with `understand-project-structure`, especially in an unfamiliar LikeC4 workspace. Then confirm or reconstruct the C1 boundary so you know which system, actors, and external systems the new work belongs to. After that, design the C2 model by identifying the containers and their typed interactions. Use `create-element` for container declarations, `create-relationship` for relationship kinds and labels, and `design-view` for the actual C2 view; finish with `test-model` to validate the result.

Use the modeling skill first, then the description skill. For the processing service, start with `create-element` and model it as a `Container_ProcessingServer`; for the production VM, start with `model-deployment-infrastructure` and model a `Node_Vm` in the right environment/zone, ideally hosting the service via `instanceOf`. After the elements exist, choose a rich description format matched to the element type: service-focused for the processing service, ops-focused for the VM. Keep the service description about purpose, inputs/outputs, dependencies, and processing behavior; keep the VM description about placement, hosting role, network surfaces, capacity, monitoring, and operational constraints.

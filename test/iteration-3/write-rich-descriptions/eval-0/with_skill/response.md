Create the elements first. For the processing service, start with the create-element skill. For the production VM, start with the model-deployment-infrastructure skill. Once they exist, choose the description format by element type: for the service, use a prose description and add a metadata {} block only when you need queryable fields such as owner or regions; for the VM, use a Markdown table in the description for ops-readable specs, with optional metadata only if automation must query those values.

In this repo, the clean bootstrap is to create `projects/payments/` from `projects/template/`. The minimum files are: `projects/payments/likec4.config.json` (set the project `name` and `title`, keep `include.paths` pointing to `../shared`, keep `imageAliases.@` pointing to `../shared/images/`), `projects/payments/system-model.c4` (define payments actors, systems, containers, and relationships), and `projects/payments/system-views.c4` (add the index view and at least one C1/C2 view). `projects/payments/ADR/` is optional but useful for local architectural decisions. Practical sequence: copy the template, rename metadata, replace the sample `mySystem`/`user` model with payments elements, then add views. Use `projects/spec-showcase/` as a reference example, not as the source template.

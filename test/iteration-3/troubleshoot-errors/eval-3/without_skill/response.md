The root cause is duplicated meaning across two levels of the model. In this workspace logical application traffic belongs in `model {}` using the business relationship types from `projects/shared/spec-global.c4`, while `projects/shared/SPEC_CHEATSHEET.md` explicitly says deployment relationships such as `https` are for infrastructure-specific links and normal traffic should be inherited in deployment through `instanceOf`. The clean fix is to model the logical call once, for example `webapp -[calls]-> api` with `technology 'HTTPS'`, and then let the deployed app instances inherit that relationship. Remove the copied deployment app-to-app edge unless it represents a genuinely infrastructure-only link such as proxy-to-VM, load balancer-to-node, backup NFS, or another network path that does not exist as a logical system interaction.

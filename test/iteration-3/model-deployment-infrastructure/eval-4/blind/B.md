Add the Prometheus scrape as a deployment relationship if it is an operations-only concern that is not already modeled logically. If Prometheus scrapes host-level metrics, a VM-level edge such as `prometheusVm -[http]-> apiVm 'Scrapes metrics'` is appropriate. If it scrapes the application endpoint, point it to `apiApp` instead. Avoid duplicating browser-to-API and API-to-database deployment edges when those interactions already exist in the logical model and the deployed nodes are linked with `instanceOf`; those should be inherited rather than redrawn manually. In short: add monitoring, backup, ingress, and other deployment-specific links; do not re-copy ordinary user/application traffic just to make the deployment diagram busier.

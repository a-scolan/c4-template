This skill is the right one for the base deployment framework: it tells you to model `Node_Environment -> Zone -> Node_Vm -> Node_App`, use consistent VM naming, add rich infrastructure descriptions, and connect runtimes with `instanceOf`. If your main goal is specifically how to split production into `Dmz`, `AppTier`, `ProcTier`, and `DataTier` and define firewall rules between those zones, switch to `structure-deployment-tiers`. Keep the boundary explicit: this skill covers honest infrastructure modeling; `structure-deployment-tiers` is the next step for tier organization and firewall design.

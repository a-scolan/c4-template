Usually no. The repository guidance says interaction technology belongs on the system-model relationship, while deployment relationships are for infrastructure-specific connections. So do not add `Prod.Web.webApp -[https]-> Prod.App.apiApp` or `Prod.App.apiApp -[tcp]-> Prod.Data.dbApp` just to restate normal logical traffic. Put the technology on the logical relationships instead, for example `technology 'HTTPS'` on the web/API relationship and database technology on the API/MongoDB relationship. Add a port only when it is non-default for that protocol or technology. Use deployment relationships only when the deployment view needs an extra infrastructure edge that does not already exist logically.

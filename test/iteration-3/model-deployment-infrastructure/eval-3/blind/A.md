Those deployment relationships should generally not be added for normal application traffic. The `HTTPS`, `HTTP/8080`, database port, or similar technology details belong on the system-model relationships, not duplicated in `deployment.c4`. For example, put the protocol on the logical edges such as `web -> api { technology 'HTTPS' }` and `api -> db { technology 'TCP/27017' }` or whatever logical relationship kind your model uses. In deployment, make the runtime nodes `Node_App` instances and link them with `instanceOf`; the deployed instances inherit those logical relationships automatically. Reserve explicit deployment relationships only for infrastructure-specific exceptions such as Prometheus scraping, replication, backup agents, log shipping, bastion access, or an operational network hop that is not represented in the logical model.
